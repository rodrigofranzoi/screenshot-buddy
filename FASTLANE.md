# Fastlane — Capture Buddy (macOS App Store)

Sign a Mac App Store build, upload it, and push **STORE.md** translations + **docs/screenshots/*/banners** to App Store Connect.

Shared lanes live in `Vendor/shared-buddy/scripts/store/Fastfile`. Metadata is generated by `prepare_deliver_metadata.py` (do not edit `fastlane/metadata` or `fastlane/screenshots` by hand).

## Lanes

Generate screenshots before uploading:

```bash
./scripts/generate-store-screenshots.sh
```

| Lane | What it does |
|------|----------------|
| `bundle exec fastlane mac prepare` | Build `fastlane/metadata` + `fastlane/screenshots` from `STORE.md` and banner PNGs |
| `bundle exec fastlane mac build` | Archive + export signed Mac App Store `.pkg` into `build/` |
| `bundle exec fastlane mac beta` | Build + upload `.pkg` to TestFlight |
| `bundle exec fastlane mac metadata` | Upload listing copy + screenshots (no binary) |
| `bundle exec fastlane mac screenshots` | Upload screenshots only |
| `bundle exec fastlane mac release` | Build + upload binary, metadata, and screenshots |
| `bundle exec fastlane mac release submit:true` | Same as release, then submit for App Review |

Examples:

```bash
# Dry-run metadata generation (no ASC upload)
bundle exec fastlane mac prepare

# Push translations + 1280×800 banners for every locale
bundle exec fastlane mac metadata

# Ship a build and refresh the store listing
bundle exec fastlane mac release

# Submit for review in one shot
bundle exec fastlane mac release submit:true
```

## Source of truth

| Field | Source |
|-------|--------|
| Name, subtitle, keywords, promo, description | `STORE.md` locale sections |
| What’s New | `STORE.md` → What’s New (all locales) |
| Privacy / Terms URLs | `STORE.md` Legal URLs |
| App Review notes | `STORE.md` App Review Notes fenced block |
| Screenshots | `docs/screenshots/{en,de,…}/banners/*.png` (ordered per feature) |

Locale map: `en→en-US`, `de→de-DE`, `nl→nl-NL`, `pt→pt-PT`, `es→es-ES`, `fr→fr-FR`, `it→it`, `ar→ar-SA`, `zh→zh-Hans`, `ru→ru`, `ja→ja`.
