# Store Copy — Screenshot Buddy

## App Store (English)

**Name:** Screenshot Buddy  
**Subtitle:** Edit, redact & organize shots  
**Keywords:** screenshot,capture,annotate,blur,redact,editor,menu bar  

**Description:**

Screenshot Buddy saves your captures in a clean gallery and lets you quick-edit: draw, add text, blur, or black-box sensitive areas.

Detects likely passwords, IBANs, and other sensitive patterns so you can redact in one tap. Save As, overwrite, or copy back to the clipboard.

Menu bar access to recent shots. Built for macOS accessibility.

**What's New:** Initial release.

**Privacy nutrition (summary):** Screenshots stay on device. Optional analytics (no image content).
